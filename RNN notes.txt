It is representeed in matrix format  called as X


-----------------------------------------------------------------------

so for each word we will be going to created query vector, key vector and value vector

query-- what i am looking for

key- what information does each words contains (represent each words and help determine which words are relevant)

value- what actual information should i take from that words

Next step is to assume the weeights of query (wq), key (wk), value vector (wv)


------------------------------------------------------------------------

Calcualte query =  X (input matrix)  * Wq (weight of query matrix)
Calcualte key =  X (input matrix)  * Wk (weight of key matrix)
Calcualte value =  X (input matrix)  * Wv (weight of value matrix)

------------------------------------------------------------------------
compute attention score
                    Take the transpose of key matrix (kt)
 

attention score= Query matrix (Q) * Kt (transpose of key matrix)
---------------------------------------------------------------------------
Applying the softmax to get the attention weights matrix

compute weighted sum of values
output = Attention weights matrix * value matrix
------------------------------------------------------------------------------

After this feed forward neural network process the information from the previous layer and pass it out the next encoder.
